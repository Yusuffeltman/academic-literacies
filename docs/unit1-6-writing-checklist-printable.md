## Unit 6 Full-Essay Gate (all must be met)
- [ ] Clear thesis and sustained argument line
- [ ] Intro + 3 body paragraphs + counter/rebuttal + conclusion
- [ ] Minimum 3 credible sources integrated and cited
- [ ] Reference list accurate
- [ ] Revision evidence (draft -> feedback -> revised draft)

## Scale Reminder
- 1 = Emerging
- 2 = Developing
- 3 = Proficient
- 4 = Strong/Independent

## Fairness Rule
Standards stay the same for all pathways; only scaffolding and support differ.
