How to Sign In to Academic Literacies

Follow these steps to sign in. You do not need a password — we will email you a 6-digit code instead.

1
 Open the app

Go to academic-literacy.web.app in your browser. The Student Sign In tab should already be selected.

Tips

  • Use the same email that is on your class record
  • The code arrives in seconds — check Spam/Junk if you don't see it
  • Each code expires after 10 minutes — request a new one if it expires
  • You can only request a new code once per minute
  • Do not share your code with anyone
Still can't sign in? Contact your lecturer and include your student number and personal email address.
