# Academic Literacies Student Android Install Guide

This guide is for students installing the Android app before it is published on Google Play.

## Student link to share

Share the hosted download page, not only the APK file.

Recommended student entry point:

```text
https://YOUR-HOST/academic-literacies/1.1.0/download-page/
```

The download page included in the distribution pack gives students:

- a direct APK download button
- install instructions
- a QR code that points to the direct APK file

## Student install steps

1. Open the download page on your Android phone.
2. Tap `Download APK`.
3. If Android blocks the install, allow `Install unknown apps` for the browser or files app that opened the APK.
4. Return to the APK and tap `Install`.
5. Open `Academic Literacies Student`.
6. Sign in with your academic account.

## Message to students about safety

Use this explanation in plain language:

> This app is being distributed directly by the module team before Play Store release. Android may ask for permission to install from the browser because the app is not yet published through Google Play.

## What to test before broad student release

- The hosted download page opens on Android.
- The QR code loads on the hosted page.
- The QR code points to the direct APK.
- The APK installs successfully on at least one Samsung and one other Android device.
- Students can sign in and reach the Android student home screen.
