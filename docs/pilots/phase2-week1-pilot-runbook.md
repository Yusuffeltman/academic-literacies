# Phase 2 Week 1 Pilot Runbook

This pilot tests differentiated delivery in Phase 2 using one source-evaluation task and one claim-writing task per pathway.

## Pilot Files
- Assignment set: [docs/phase2-week1-pilot.csv](./phase2-week1-pilot.csv)
- Full differentiated planner: [docs/differentiated-resource-assignment.csv](./differentiated-resource-assignment.csv)
- ILP form: [docs/ilp-template.md](./ilp-template.md)
- Moderation rubric: [docs/pathway-moderation-rubric.md](./pathway-moderation-rubric.md)

## Pilot Scope (Week 1)
Objectives tested:
- p2.source_eval.verify
- p2.write.claim_verdict

Pathways tested:
- Supported
- Core
- Advanced

Rows included:
- 6 total (2 objectives × 3 pathways)

## Delivery Protocol
1. Confirm current pathway per student using moderation records.
2. Assign matching row from [docs/phase2-week1-pilot.csv](./phase2-week1-pilot.csv).
3. Run source-evaluation task first, then claim-writing task.
4. Require evidence outputs exactly as listed in pilot CSV.
5. Add one bounded learner-choice element (choice of example set, audience framing, or response structure).
6. Record outcomes in ILP checkpoints and tutor notes.

## Tutor Session Structure
- 10 min: objective framing and evidence criteria
- 20 min: source verification task
- 20 min: claim verdict writing task
- 10 min: self-check + AI prompt-based revision
- 10 min: tutor feedback and ILP updates

## Evidence to Collect
For each student:
- source-check artifact
- claim-writing artifact
- completion status and time-to-complete
- quality note against pathway expectation
- one revision action after feedback
- soft-skill observation (critical judgement, communication, self-management)
- 80-120 word double-loop reflection (what changed in understanding + what changed in strategy)

## Week-End Evaluation Metrics
- Completion rate by pathway
- Quality attainment by pathway (met / partially met / not met)
- Revision uptake rate
- Time-on-task realism (too easy / fit / too hard)
- Placement confidence (hold / adjust)
- Unit 6 essay-readiness indicator (on track / at risk) based on thesis clarity, structure control, and evidence integration
- Learner-agency indicator (choice quality + reflection quality)

## Decision Rules After Pilot
- If students complete rapidly with shallow evidence quality: increase challenge requirements.
- If completion is low with high confusion: increase scaffolding.
- If quality and pacing are balanced: keep and scale.

## Fortnight Integration
Use this pilot evidence in moderation to:
- confirm pathway placement,
- update ILPs,
- flag high-priority resource gaps for supported and advanced pathways.

## Unit 6 Essay Target Alignment
This Phase 2 pilot is part of the accelerated trajectory to full essays by Unit 6.
During ILP updates, record whether each student is on track for the Unit 6 benchmark:
- 700-900 word full essay,
- thesis + 3 body paragraphs + counter-argument/rebuttal + conclusion,
- minimum 3 credible sources,
- evidence of revision after feedback.
