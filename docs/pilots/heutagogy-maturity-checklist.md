# Heutagogy Maturity Checklist (Module Audit)

Purpose: Audit how strongly the live module operates as self-directed (heutagogical) learning.

Use with:
- [docs/reviewed-module-differentiation-plan.md](./reviewed-module-differentiation-plan.md)
- [docs/ilp-template.md](./ilp-template.md)
- [docs/heutagogy-observation-rubric.md](./heutagogy-observation-rubric.md)

## Maturity Scale (0-3)
- 0 = Not present
- 1 = Emerging (occasional / optional)
- 2 = Embedded (regular but inconsistent)
- 3 = Systemic (required and consistently evidenced)

## Audit Dimensions
1. Learner contract and negotiated goals
2. Learner choice in inquiry/output mode (bounded autonomy)
3. Self-determined evidence pathways
4. Double-loop reflection (what changed + how strategy changed)
5. Capability/transfer portfolio evidence
6. Co-assessment (student self-rating vs tutor/lecturer rating)
7. Pathway flexibility and opt-up access
8. AI as metacognitive coach (not answer engine)
9. Fairness safeguards (common standards, moderated decisions)
10. Continuation readiness (independent learning beyond module)

Note: baseline scores are provisional planning estimates and should be validated with live teaching evidence.

## Classification Guide
- 0-9: Predominantly teacher-directed
- 10-17: Hybrid (andragogy-forward with limited heutagogy)
- 18-24: Emerging heutagogical system
- 25-30: Strong systemic heutagogy

## Immediate Module Strengthening Priorities
1. Make learner contract mandatory in every ILP cycle.
2. Require one bounded learner-choice task per two-week cycle.
3. Require one double-loop reflection artifact per cycle.
4. Require one capability transfer artifact per phase.
5. Run co-assessment calibration fortnightly.

## Minimum Evidence Pack for “Heutagogy Active” status
A phase can be marked “heutagogy active” only when all are present:
- learner contract completed by >80% students,
- bounded choice task completed by >80%,
- double-loop reflection quality at least “developing” for >70%,
- portfolio transfer artifact submitted by >70%,
- moderation confirms fairness controls active.
